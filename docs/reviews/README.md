# docs/reviews

Code review, QA, and (when applicable) security review results — one file per task.

- Template: `templates/REVIEW_TEMPLATE.md`
- Naming: `YYYY-MM-DD-<task-slug>-review.md` (same slug as the task)
- Final status: `APPROVED` / `APPROVED_WITH_COMMENTS` / `CHANGES_REQUESTED` / `BLOCKED`

Never store secrets, credentials, or customer data here.
