# docs/investigations

Investigations of bugs, integration problems, and external-system behavior.

- Template: `templates/INVESTIGATION_TEMPLATE.md`
- Naming: `YYYY-MM-DD-<short-slug>.md`
- Investigations are read-only by default; consequential actions are proposed, not performed,
  without explicit human approval.

Never store secrets, credentials, tokens, or customer data here. Redact evidence.
