# docs/tasks

Task specifications, bug reports, and parallel execution plans.

- Features/changes: from `templates/TASK_TEMPLATE.md`
- Bugs: from `templates/BUG_TEMPLATE.md`
- Parallel plans: from `templates/PARALLEL_EXECUTION_TEMPLATE.md` (`-parallel-plan` suffix)
- Naming: `YYYY-MM-DD-<short-slug>.md`
- Status flow: `DRAFT` → `APPROVED` → `IN_PROGRESS` → `IMPLEMENTED` → `IN_REVIEW` → `DONE`

Never store secrets, credentials, or customer data here.
